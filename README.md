### Featured projects

**[FairShare](https://github.com/mohadikarmrunal/FairShare)** · *React Native, TypeScript, Google Sheets*
An expense-splitting app with no server: each trip is a Google Sheet in your own Drive. It works offline, calculates balances on the phone and suggests payments to settle up. Built with Claude Code, including AI review agents for security, tests and settlement checks, and an MCP server that lets Claude add expenses from a plain sentence. Android beta; iOS in progress.

**[ThinkingPartner](https://github.com/mohadikarmrunal/thinkingpartner)** · *Python, Swift, local LLMs*
A live AI assistant for meetings, lectures and brainstorms. It transcribes the conversation on-device (Whisper), grounds its suggestions in your own documents, and shows them on a second device such as an iPad. It runs fully on a Mac with Qwen via Ollama, with optional Claude or ChatGPT.

**Beer Distribution Game in VR** · *Unity, C#, PHP, MySQL*
A multi-player VR and web version of the classic supply chain game, with synchronized players and full decision logging, built for controlled experiments at TUM.
